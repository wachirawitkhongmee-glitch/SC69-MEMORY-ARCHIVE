# MEMORY MIRROR SC69
### สมุดกระจกแห่งความทรงจำ
> **"A little letter, a lifetime memory."**  
> **From: ต้นปาล์ม ♡**

---

## 📖 1. เกี่ยวกับโครงการ (Project Overview)

**Memory Mirror SC69 (สมุดกระจกแห่งความทรงจำ)** เป็นเว็บไซต์สำหรับส่งต่อจดหมาย คำอวยพร และข้อความให้กำลังใจแก่เพื่อน ๆ คณะกรรมการสภานักเรียน โรงเรียนบดินทรเดชา (สิงห์ สิงหเสนี) ๒ รุ่น 69 โดยผู้รับแต่ละคนจะได้รับจดหมายและความทรงจำที่เขียนขึ้นมาเพื่อพวกเขาโดยเฉพาะ

แนวคิดหลักของงานออกแบบคือ **Antique Vintage Letter ผสมผสานกับ Old Memory Scrapbook** ให้ความรู้สึกเหมือนกำลังค้นพบหีบจดหมายเก่าบนโต๊ะไม้คลาสสิกที่เก็บเรื่องราว ความผูกพัน และรอยยิ้มเอาไว้

**ผู้เขียนจดหมายทุกฉบับคือ ต้นปาล์ม เท่านั้น**

## ✨ 2. ฟังก์ชันและจุดเด่นหลัก (Key Features)

### ✉️ 1. หน้าแรก (Landing Page — โต๊ะเขียนจดหมายเก่า)
- บรรยากาศโต๊ะไม้โบราณ แสงไฟอบอุ่น และละอองฝุ่นแสงสีทอง (Floating Dust Particles) ลอยละล่องผ่านลำแสง
- ซองจดหมายสไตล์วินเทจแบบ 3D Perspective มีมิติและเงาสมจริง
- ตราประทับครั่งสีแดงเข้ม (Deep Burgundy Wax Seal) นูนต่ำตรา SC69 ♡
- แสตมป์วินเทจพร้อมรอยประทับตราไปรษณีย์คลื่น (Postmark Cancellation)
- เชือกป่านและดอกลาเวนเดอร์แห้งผูกประดับ
- ป้ายชื่อกระดาษระบุ "From: ต้นปาล์ม ♡"
- ปุ่ม **OPEN LETTER** ออกแบบเหมือนป้ายแท็กกระดาษเก่าห้อยเชือกพร้อมรูตาไก่โลหะ

### 🎬 2. Animation การเปิดจดหมาย (Smooth Cinematic Sequence)
เมื่อกดปุ่ม OPEN LETTER หรือคลิกที่ตราครั่ง:
1. **เริ่มเล่นเพลง "หัวใจผูกกัน - Acoustic" ทันที** (เริ่มจากการคลิกของผู้ใช้ตามนโยบายเบราว์เซอร์)
2. ตราครั่งแตกออกเป็นเศษอนุภาค (Wax Shatter Particles) พร้อมเสียง Crack สมจริง
3. ฝาซองจดหมายค่อย ๆ พับเปิดขึ้นในแบบ 3D (`rotateX(-180deg)`)
4. กระดาษจดหมายค่อย ๆ เลื่อนลอยขึ้นจากซองพร้อมเงาตกกระทบและเสียงกรอบแกรบ
5. เปลี่ยนเข้าสู่หน้าบัตรลงทะเบียนรับจดหมายอย่างนุ่มนวล

### 🎶 3. ระบบเพลงประกอบ (Music Player — หัวใจผูกกัน - Acoustic)
- เล่นเพลงต่อเนื่องแบบ Single Page Application (SPA) ไม่สะดุดหรือเริ่มใหม่เมื่อเปลี่ยนหน้า
- กล่องควบคุมเพลงสไตล์วินเทจทำจากทองเหลืองและไม้มะฮอกกานี
- **แผ่นเสียงไวนิลหมุนช้า ๆ** ขณะเพลงกำลังเล่น
- **แถบ Equalizer Soundwave** ขยับตามจังหวะเสียงดนตรี
- ปุ่ม Play / Pause และปุ่ม Mute / Unmute
- **ตำแหน่งไฟล์เพลง:** `assets/audio/heart-tied-acoustic.mp3`
- **Graceful Acoustic Fallback:** หากยังไม่มีไฟล์ MP3 เว็บไซต์จะสังเคราะห์เสียงอะคูสติกนุ่มนวล (Acoustic Chords Ambient Generator) ผ่าน Web Audio API อัตโนมัติ เพื่อให้ผู้ใช้สัมผัสบรรยากาศความทรงจำได้ทันทีโดยไม่เกิด error หรือเสียงขาดหาย

### 🏷️ 4. ระบบระบุชื่อผู้รับ (Recipient Registry Card)
- ออกแบบเหมือนบัตรดัชนีไปรษณีย์เก่า (Postal Registry Archive Card)
- หัวข้อ "จดหมายฉบับนี้ส่งถึงใครนะ?"
- ค้นหาได้ทั้ง **ชื่อจริง, นามสกุล, ชื่อเล่น, และชื่อเรียกแทน** (ทั้งภาษาไทยและภาษาอังกฤษ เช่น "กันต์", "Gun", "ปธ", "เจมส์", "James", "พีช", "แพร", "ไอซ์", "ภูมิ", "พลอย", "SC69")
- ระบบค้นหาแบบยืดหยุ่น (Fuzzy Matching & Prefix Strip)
- หากไม่พบชื่อ จะแสดงข้อความอบอุ่น: *"เหมือนจะยังไม่มีจดหมายของชื่อนี้นะ ลองตรวจสอบชื่ออีกครั้ง"*
- เมื่อพบชื่อ จะแสดง Animation **ตราประทับหมึกยางสีแดง "APPROVED"** กระแทกลงบนการ์ดอย่างทรงพลังก่อนเปิดจดหมาย

### 📜 5. หน้าจดหมายส่วนตัว (Personal Letter)
- กระดาษเนื้อโบราณ (Aged Parchment) มีเส้นบรรทัดจาง ๆ ขอบกระดาษขรุขระ (Deckled Edge) และรอยหมึกคลาสสิก
- มุมบนระบุ: `Dear [ชื่อผู้รับ],` พร้อมป้ายแสดงบทบาท/ฝ่ายงาน
- ตราประทับวันที่วงกลม (Circular Postmark Bangkok SC69)
- Animation ข้อความค่อย ๆ ปรากฏเหมือนหมึกกำลังจรดลงบนกระดาษ (Handwriting Reveal) สามารถคลิกเพื่อข้ามได้
- ข้อความลงท้ายคงที่:
  > **ด้วยความหวังดีและความทรงจำดี ๆ**  
  > **จาก ต้นปาล์ม ♡**

### 📷 6. Memory Wall — รูปภาพแขวนบนเชือก (หนึ่งในจุดเด่นที่สุด)
- เชือกป่านพาดผ่านบริเวณด้านบนของแกลเลอรี
- รูปภาพกรอบ **Polaroid** พร้อม **ไม้หนีบไม้ (Wooden Clothespins)** ขนาดกะทัดรัด
- รูปแต่ละใบเอียงในองศาที่แตกต่างกันอย่างเป็นธรรมชาติ (-3.5° ถึง +3.8°)
- Animation แกว่งไหวช้า ๆ เสมือนแขวนรับสายลมอ่อน ๆ (Swaying Motion)
- เมื่อเอาเมาส์ไปวาง (Hover) รูปจะยกตัวขึ้น ขยายใหญ่ และหมุนตรงพร้อมเงาที่นุ่มนวล
- เอฟเฟกต์ **3D Tilt ตามตำแหน่งเมาส์**
- เมื่อคลิก จะเปิด **Lightbox ภาพขยายความละเอียดสูง** พร้อม Caption และวันที่
- รองรับหลายรูปต่อหนึ่งคน และจัดเรียง Responsive สวยงามบนหน้าจอมือถือ

### 🔒 7. Secret Letter — จดหมายลับ
- ซองจดหมายเล็ก ๆ ซ่อนอยู่ภายในหน้าจดหมาย
- ปุ่มกด: *"จดหมายลับจากต้นปาล์ม (คลิกเพื่อเปิดอ่าน ✉️)"*
- เมื่อคลิก ซองเล็กจะคลี่เปิดออกและแสดงข้อความความในใจพิเศษเฉพาะบุคคลจากต้นปาล์ม

### 📦 8. ปุ่มเก็บจดหมายไว้ในความทรงจำ
- ปุ่ม *"เก็บจดหมายฉบับนี้ไว้ในความทรงจำ"*
- กระดาษจดหมายจะค่อย ๆ พับและเก็บกลับเข้าสู่ซอง พร้อมแสดงข้อความเตือนใจ:  
  **"Keep this memory close to your heart. จดหมายฉบับนี้ถูกเก็บไว้ในความทรงจำแล้ว ♡"**

## 🛠️ 3. ระบบจัดการหลังบ้าน (Admin Dashboard)

เข้าใช้งานผ่านปุ่ม **Admin** มุมขวาบน หรือไฟล์ `admin.html`:
- **ระบบยืนยันตัวตน:** รหัสผ่านเริ่มต้น `tonpalm69` (หรือ `sc69admin`)
- **ผู้เขียนถูกล็อคเป็น "ต้นปาล์ม" เสมอ:** ไม่ต้องกรอกซ้ำในแต่ละจดหมาย
- **เพิ่ม / แก้ไข / ลบ จดหมาย:** ระบุชื่อ, ชื่อเล่น, คำค้นหา, ฝ่ายงาน, เนื้อหาจดหมายหลัก, และข้อความลับ
- **อัปโหลดรูปภาพหลายรูปพร้อมกัน:** รองรับการบีบอัดภาพอัตโนมัติ, เพิ่ม Caption, จัดการและลบรูปภาพ
- **ดูตัวอย่างจดหมายสด (Live Preview):** ดูตัวอย่างหน้าจดหมาย กระดาษ และรูปแขวนเชือกเสมือนจริงก่อนเผยแพร่
- **สถานะเผยแพร่ / แบบร่าง (Publish / Draft Toggle)**
- **ระบบสำรองและกู้คืน (Backup & Restore):** Export ข้อมูลเป็น JSON และ Import กลับเข้ามาได้ตลอดเวลา
- **ปุ่มคืนค่าเริ่มต้น (Reset to SC69 Defaults):** กู้คืนข้อมูลตัวอย่างของเพื่อนสภา 69 ได้ในคลิกเดียว

## 🎵 5. คำแนะนำสำหรับการใส่ไฟล์เสียงและรูปภาพ

1. **ระบบเพลง "หัวใจผูกกัน - Acoustic":**
   - **YouTube Official Integration:** ระบบเชื่อมต่อเพลง "หัวใจผูกกัน - Acoustic" จาก YouTube (`DA_JjHpVRRY`) อัตโนมัติ โดยเล่นเพลงเป็นซาวด์แทร็กแบ็กกราวนด์ที่ควบคุมผ่านเครื่องเล่นเพลงวินเทจได้อย่างสมบูรณ์แบบ
   - **ไฟล์เสียง MP3 สำรอง:** หากต้องการใช้ไฟล์เสียงในเครื่อง สามารถวางไฟล์ที่ `assets/audio/heart-tied-acoustic.mp3`
   - **Acoustic Synthesizer Fallback:** หากออฟไลน์หรือไม่มีอินเทอร์เน็ต ระบบยังมีเสียงจำลองอะคูสติก Web Audio ให้บรรยากาศอบอุ่นอยู่เสมอ

2. **รูปภาพ:**
   - ได้คัดลอกรูปภาพสมาชิกสภา SC69 จากชุดเดิมมาไว้ใน `assets/images/photos/` เรียบร้อยแล้ว (37 ภาพ)
   - สามารถอัปโหลดรูปภาพเพิ่มเติมได้ตลอดเวลาผ่านหน้า Admin (`admin.html`)

## 🚀 6. วิธีการเปิดใช้งานเว็บไซต์

คุณสามารถเปิดไฟล์ `index.html` บนเบราว์เซอร์ได้ทันที หรือรันเซิร์ฟเวอร์จำลองด้วย Node.js:

```bash
node server.js
```

จากนั้นเปิดเบราว์เซอร์ไปที่:  
`http://localhost:3000/`

หรือเปิดหน้าแอดมิน:  
`http://localhost:3000/admin.html` (รหัสผ่าน: `tonpalm69`)
